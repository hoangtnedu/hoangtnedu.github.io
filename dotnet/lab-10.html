Lab 10. DataAdapter, DataTable, DataSet và dữ liệu ngắt kết nối

Bài tập Chương 4 · Truy cập dữ liệu với ADO.NET.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Sử dụng SqlDataAdapter để Fill DataTable và DataSet.
  • Tạo và thao tác DataTable, DataRow, DataColumn trong bộ nhớ.
  • Thiết lập DataRelation giữa các bảng.
  • Lọc, sắp xếp bằng DataView và cập nhật dữ liệu qua DataAdapter.

2. Công cụ và dữ liệu chuẩn bị

  • CSDL QLSinhVien.
  • Project Lab10_DisconnectedData.
  • System.Data, SqlDataAdapter và SqlCommandBuilder.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Chuyển từ đọc tuần tự bằng DataReader sang mô hình ngắt kết nối. DataSet nhiều bảng sẽ được dùng cho master-detail và báo cáo ở các lab tiếp theo.

4. Chuẩn bị trước khi thực hành

  • Ôn mô hình connected và disconnected ADO.NET.
  • Tạo Form có hai DataGridView Khoa và SinhVien.
  • Sao lưu database trước khi thử cập nhật trực tiếp.

5. Bài tập có hướng dẫn và code mẫu

1. Fill DataTable bằng SqlDataAdapter

Yêu cầu: Nạp bảng SinhVien vào DataTable và gán DataGridView. Gợi ý triển khai: Adapter tự mở và đóng kết nối khi Fill nếu kết nối đang đóng.

private DataTable GetStudentTable()
{
  DataTable table = new DataTable("SinhVien");
  using (SqlConnection conn = DbConnectionFactory.Create())
  using (SqlDataAdapter adapter = new SqlDataAdapter(
    "SELECT * FROM SinhVien ORDER BY MaSV", conn))
  {
    adapter.Fill(table);
  }
  return table;
}

2. DataSet chứa nhiều bảng

Yêu cầu: Nạp Khoa và SinhVien vào cùng DataSet với tên bảng rõ ràng. Gợi ý triển khai: Tên bảng giúp truy cập ổn định hơn chỉ số 0,1.

DataSet ds = new DataSet("QLSinhVien");
using (SqlConnection conn = DbConnectionFactory.Create())
{
  new SqlDataAdapter("SELECT * FROM Khoa", conn).Fill(ds, "Khoa");
  new SqlDataAdapter("SELECT * FROM SinhVien", conn).Fill(ds, "SinhVien");
}
dgvKhoa.DataSource = ds.Tables["Khoa"];
dgvSinhVien.DataSource = ds.Tables["SinhVien"];

3. Thiết lập DataRelation Khoa - SinhVien

Yêu cầu: Tạo quan hệ giữa MaKhoa của hai DataTable và lấy các dòng con. Gợi ý triển khai: Dữ liệu phải bảo đảm toàn vẹn khóa trước khi tạo quan hệ.

DataRelation relation = new DataRelation(
  "FK_Khoa_SinhVien",
  ds.Tables["Khoa"].Columns["MaKhoa"],
  ds.Tables["SinhVien"].Columns["MaKhoa"]);
ds.Relations.Add(relation);

DataRow khoa = ds.Tables["Khoa"].Rows[0];
DataRow[] sinhVien = khoa.GetChildRows("FK_Khoa_SinhVien");
foreach (DataRow row in sinhVien)
  Console.WriteLine(row["HoTen"]);

4. Lọc và sắp xếp bằng DataView

Yêu cầu: Lọc sinh viên theo khoa và điểm tối thiểu mà không truy vấn lại CSDL. Gợi ý triển khai: Escape dấu nháy trong giá trị chuỗi khi tạo RowFilter.

DataView view = new DataView(ds.Tables["SinhVien"]);
string maKhoa = cboKhoa.SelectedValue.ToString().Replace("'", "''");
view.RowFilter = string.Format("MaKhoa = '{0}' AND DiemTB >= {1}",
   maKhoa, numMinDiem.Value.ToString(System.Globalization.CultureInfo.InvariantCulture));
view.Sort = "DiemTB DESC, HoTen ASC";
dgvSinhVien.DataSource = view;

5. Cập nhật bằng SqlCommandBuilder

Yêu cầu: Cho phép sửa dữ liệu trực tiếp trên DataGridView và gửi thay đổi về CSDL. Gợi ý triển khai: Câu SELECT phải trả khóa chính; dùng command builder cho bài tập cơ bản.

private SqlDataAdapter _adapter;
private DataTable _table;

private void LoadData()
{
  SqlConnection conn = DbConnectionFactory.Create();
  _adapter = new SqlDataAdapter("SELECT * FROM SinhVien", conn);
  new SqlCommandBuilder(_adapter);
  _table = new DataTable();
  _adapter.Fill(_table);
  dgvSinhVien.DataSource = _table;
}

6. Bài tập tự thực hiện - không có code gợi ý

7. Theo dõi RowState

Yêu cầu: Hiển thị các dòng Added, Modified, Deleted trước khi gọi Update; dùng GetChanges().

Yêu cầu: Tạo nút Chấp nhận thay đổi cục bộ và Hoàn tác; giải thích ảnh hưởng tới Update.
