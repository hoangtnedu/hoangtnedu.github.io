Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Đọc dữ liệu theo mô hình kết nối bằng SqlDataReader.
  • Hiển thị dữ liệu lên DataGridView bằng DataTable hoặc nạp thủ công.
  • Xây dựng tìm kiếm, lọc, sắp xếp và phân trang bằng SQL tham số hóa.
  • Đồng bộ dòng chọn với vùng thông tin chi tiết.

2. Công cụ và dữ liệu chuẩn bị

  • CSDL QLSinhVien.
  • Project Lab09_DataReaderSearch.
  • DataGridView, ComboBox, BindingSource.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Tập trung chức năng tra cứu dữ liệu. Lab 10 sẽ triển khai mô hình ngắt kết nối bằng DataAdapter, DataTable và DataSet.

4. Chuẩn bị trước khi thực hành

  • Bổ sung dữ liệu đủ lớn để có ít nhất 3 trang.

  • Ôn JOIN, LIKE, BETWEEN, ORDER BY và OFFSET-FETCH.

5. Bài tập có hướng dẫn và code mẫu

1. Nạp SqlDataReader vào DataTable

Yêu cầu: Đọc danh sách sinh viên kèm tên khoa và hiển thị trên DataGridView. Gợi ý triển khai: DataTable.Load(reader) giúp chuyển dữ liệu reader sang bảng bộ nhớ.

  private DataTable LoadStudents()
  {
    string sql = @"SELECT sv.MaSV, sv.HoTen, sv.NgaySinh,
                 CASE sv.GioiTinh WHEN 1 THEN N'Nam' ELSE N'Nữ' END AS GioiTinh,
                 k.TenKhoa, sv.DiemTB, sv.Email
             FROM SinhVien sv JOIN Khoa k ON sv.MaKhoa=k.MaKhoa";
    DataTable table = new DataTable();
    using (SqlConnection conn = DbConnectionFactory.Create())
    using (SqlCommand cmd = new SqlCommand(sql, conn))
    {
       conn.Open();
       using (SqlDataReader reader = cmd.ExecuteReader()) table.Load(reader);
    }

    return table;
}

2. Tìm kiếm gần đúng theo họ tên

Yêu cầu: Tìm sinh viên có họ tên chứa từ khóa, không nối chuỗi SQL. Gợi ý triển khai: Thêm ký tự % vào giá trị tham số.

private DataTable SearchByName(string keyword)
{
  string sql = @"SELECT MaSV, HoTen, MaKhoa, DiemTB
           FROM SinhVien
           WHERE HoTen LIKE @Keyword
           ORDER BY HoTen";
  DataTable table = new DataTable();
  using (SqlConnection conn = DbConnectionFactory.Create())
  using (SqlCommand cmd = new SqlCommand(sql, conn))
  {
     cmd.Parameters.Add("@Keyword", SqlDbType.NVarChar, 100).Value =
       "%" + keyword.Trim() + "%";
     conn.Open();
     table.Load(cmd.ExecuteReader());
  }
  return table;
}

3. Lọc theo khoa và khoảng điểm

Yêu cầu: Cho phép chọn khoa hoặc Tất cả, nhập điểm tối thiểu và tối đa. Gợi ý triển khai: Xây câu SQL theo các bộ lọc nhưng mọi giá trị phải là parameter.

string sql = @"SELECT MaSV, HoTen, MaKhoa, DiemTB
           FROM SinhVien
           WHERE DiemTB BETWEEN @Min AND @Max";
if (!string.IsNullOrEmpty(maKhoa)) sql += " AND MaKhoa=@MaKhoa";
using (SqlCommand cmd = new SqlCommand(sql, conn))
{
   cmd.Parameters.Add("@Min", SqlDbType.Decimal).Value = min;
   cmd.Parameters.Add("@Max", SqlDbType.Decimal).Value = max;
   if (!string.IsNullOrEmpty(maKhoa))
      cmd.Parameters.Add("@MaKhoa", SqlDbType.VarChar, 10).Value = maKhoa;
   // Mở kết nối và đọc dữ liệu
}

4. Phân trang bằng OFFSET-FETCH

Yêu cầu: Hiển thị mỗi trang 10 sinh viên; có nút Trước và Sau. Gợi ý triển khai: ORDER BY là bắt buộc khi dùng OFFSET.

string sql = @"SELECT MaSV, HoTen, MaKhoa, DiemTB
         FROM SinhVien
         ORDER BY MaSV
         OFFSET @Offset ROWS FETCH NEXT @PageSize ROWS ONLY";
cmd.Parameters.Add("@Offset", SqlDbType.Int).Value = (pageIndex - 1) * pageSize;
cmd.Parameters.Add("@PageSize", SqlDbType.Int).Value = pageSize;

private void dgvSinhVien_SelectionChanged(object sender, EventArgs e)
