Bài tập Chương 1 · Nền tảng .NET và C#.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Tạo, biên dịch, chạy và gỡ lỗi một dự án C# Console trong Visual Studio.
  • Sử dụng biến, kiểu dữ liệu, toán tử, cấu trúc rẽ nhánh và cấu trúc lặp.
  • Kiểm tra dữ liệu nhập và xử lý ngoại lệ cơ bản bằng try-catch.
  • Hình thành quy tắc đặt tên, chú thích và tổ chức mã nguồn.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022 với workload .NET desktop development.
  • .NET Framework 4.8 hoặc .NET 8 cho ứng dụng Console.
  • Công cụ vẽ lưu đồ: draw.io/diagrams.net khi cần.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Lab 1 tạo nền tảng cú pháp C#. Các bài toán về sinh viên và điểm học tập sẽ được tái sử dụng khi xây dựng lớp ở Lab 2.

4. Chuẩn bị trước khi thực hành

  • Cài Visual Studio và xác nhận tạo được Console App.
  • Tạo Solution tên DotNetLabs, trong đó tạo project Lab01_Console.
  • Bật hiển thị số dòng và thử đặt breakpoint trong Visual Studio.

5. Bài tập có hướng dẫn và code mẫu

1. Tạo ứng dụng Console và nhập thông tin cá nhân

Yêu cầu: Tạo dự án Lab01_Console. Nhập họ tên, năm sinh; tính tuổi gần đúng và hiển thị thông tin theo định dạng rõ ràng. Gợi ý triển khai: Dùng Console.ReadLine(), int.TryParse() và chuỗi nội suy.

   using System;

   class Program
   {
     static void Main()
     {
        Console.OutputEncoding = System.Text.Encoding.UTF8;
        Console.Write("Họ và tên: ");
        string hoTen = Console.ReadLine();
        Console.Write("Năm sinh: ");
        int namSinh;
        if (!int.TryParse(Console.ReadLine(), out namSinh))

        {
            Console.WriteLine("Năm sinh không hợp lệ.");
            return;
        }
        int tuoi = DateTime.Now.Year - namSinh;
        Console.WriteLine("Xin chào {0}, tuổi gần đúng: {1}", hoTen, tuoi);
    }
}

2. Tính toán hình trụ

Yêu cầu: Nhập bán kính và chiều cao; tính diện tích xung quanh và thể tích. Không chấp nhận số âm hoặc bằng 0. Gợi ý triển khai: Sử dụng Math.PI và kiểu double.

double r, h;
Console.Write("Bán kính r = ");
if (!double.TryParse(Console.ReadLine(), out r) || r <= 0) return;
Console.Write("Chiều cao h = ");
if (!double.TryParse(Console.ReadLine(), out h) || h <= 0) return;

double dienTichXQ = 2 * Math.PI * r * h;
double theTich = Math.PI * r * r * h;
Console.WriteLine("Sxq = {0:N2}; V = {1:N2}", dienTichXQ, theTich);

3. Xếp loại kết quả học tập

Yêu cầu: Nhập điểm từ 0 đến 10 và xếp loại: Xuất sắc, Giỏi, Khá, Trung bình, Yếu. Gợi ý triển khai: Kiểm tra miền giá trị trước khi dùng if-else.

double diem;
if (!double.TryParse(Console.ReadLine(), out diem) || diem < 0 || diem > 10)
{
   Console.WriteLine("Điểm phải thuộc [0, 10].");
}
else if (diem >= 9) Console.WriteLine("Xuất sắc");
else if (diem >= 8) Console.WriteLine("Giỏi");
else if (diem >= 6.5) Console.WriteLine("Khá");
else if (diem >= 5) Console.WriteLine("Trung bình");
else Console.WriteLine("Yếu");

4. Menu xử lý bằng switch và vòng lặp

Yêu cầu: Tạo menu lặp cho phép tính tổng 1..n, in bảng cửu chương hoặc thoát chương trình. Gợi ý triển khai: Dùng do-while và switch.

int chon;
do
{
  Console.WriteLine("1. Tổng 1..n");
  Console.WriteLine("2. Bảng cửu chương");
  Console.WriteLine("0. Thoát");
  int.TryParse(Console.ReadLine(), out chon);
  switch (chon)
  {
     case 1:
       Console.Write("n = ");
       int n = int.Parse(Console.ReadLine());
       int tong = 0;
       for (int i = 1; i <= n; i++) tong += i;
       Console.WriteLine("Tổng = " + tong);
       break;
     case 2:

         for (int i = 1; i <= 10; i++)
           Console.WriteLine("7 x {0} = {1}", i, 7 * i);
         break;
    }
  } while (chon != 0);

5. Xử lý ngoại lệ phép chia

Yêu cầu: Nhập hai số nguyên, thực hiện phép chia và xử lý lỗi định dạng, chia cho 0. Gợi ý triển khai: Bắt ngoại lệ cụ thể trước ngoại lệ tổng quát.

try
{
   Console.Write("a = ");
   int a = int.Parse(Console.ReadLine());
   Console.Write("b = ");
   int b = int.Parse(Console.ReadLine());
   Console.WriteLine("a / b = " + (a / b));
}
catch (FormatException)
{
   Console.WriteLine("Dữ liệu phải là số nguyên.");
}
catch (DivideByZeroException)
{
   Console.WriteLine("Không thể chia cho 0.");
}
finally
{
   Console.WriteLine("Kết thúc phép tính.");
}
