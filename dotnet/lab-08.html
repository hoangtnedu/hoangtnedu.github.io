Bài tập Chương 4 · Truy cập dữ liệu với ADO.NET.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Tạo và cấu hình SqlCommand.
  • Phân biệt ExecuteReader, ExecuteScalar và ExecuteNonQuery.
  • Sử dụng SqlParameter để tránh nối chuỗi SQL.
  • Gọi Stored Procedure có tham số.

2. Công cụ và dữ liệu chuẩn bị

  • SQL Server và CSDL QLSinhVien từ Lab 7.
  • Visual Studio 2022.
  • System.Data và System.Data.SqlClient.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Thực hành thao tác trực tiếp với cơ sở dữ liệu theo mô hình kết nối. Các kỹ thuật này là nền tảng cho chức năng đọc, tìm kiếm ở Lab 9 và CRUD ở Lab 11.

4. Chuẩn bị trước khi thực hành

  • Chạy lại script CSDL Lab 7.
  • Bổ sung ít nhất 10 sinh viên để thử lọc và thống kê.
  • Ôn kiểu dữ liệu SqlDbType và DBNull.Value.

5. Bài tập có hướng dẫn và code mẫu

1. Đếm số sinh viên bằng ExecuteScalar

Yêu cầu: Lấy số lượng sinh viên và hiển thị trên Label. Gợi ý triển khai: Chuyển giá trị object trả về sang int an toàn.

private int CountStudents()
{
  using (SqlConnection conn = DbConnectionFactory.Create())
  using (SqlCommand cmd = new SqlCommand("SELECT COUNT(*) FROM SinhVien", conn))
  {
    conn.Open();
    return Convert.ToInt32(cmd.ExecuteScalar());
  }
}

2. Đọc danh sách bằng ExecuteReader

Yêu cầu: Đọc MaSV, HoTen, DiemTB và hiển thị trong ListBox.

Gợi ý triển khai: SqlDataReader là forward-only, read-only.

using (SqlConnection conn = DbConnectionFactory.Create())
using (SqlCommand cmd = new SqlCommand(
  "SELECT MaSV, HoTen, DiemTB FROM SinhVien ORDER BY HoTen", conn))
{
  conn.Open();
  using (SqlDataReader reader = cmd.ExecuteReader())
  {
    lstSinhVien.Items.Clear();
    while (reader.Read())
    {
       string line = string.Format("{0} - {1} - {2:N2}",
          reader["MaSV"], reader["HoTen"], reader["DiemTB"]);
       lstSinhVien.Items.Add(line);
    }
  }
}

3. Thêm sinh viên bằng ExecuteNonQuery

Yêu cầu: Thêm bản ghi bằng câu SQL tham số hóa và thông báo số dòng ảnh hưởng. Gợi ý triển khai: Khai báo đúng kiểu và độ dài tham số.

string sql = @"INSERT INTO SinhVien
(MaSV, HoTen, NgaySinh, GioiTinh, MaKhoa, DiemTB, Email)
VALUES (@MaSV, @HoTen, @NgaySinh, @GioiTinh, @MaKhoa, @DiemTB, @Email)";
using (SqlConnection conn = DbConnectionFactory.Create())
using (SqlCommand cmd = new SqlCommand(sql, conn))
{
   cmd.Parameters.Add("@MaSV", SqlDbType.VarChar, 15).Value = txtMaSV.Text.Trim();
   cmd.Parameters.Add("@HoTen", SqlDbType.NVarChar, 100).Value = txtHoTen.Text.Trim();
   cmd.Parameters.Add("@NgaySinh", SqlDbType.Date).Value = dtpNgaySinh.Value.Date;
   cmd.Parameters.Add("@GioiTinh", SqlDbType.Bit).Value = radNam.Checked;
   cmd.Parameters.Add("@MaKhoa", SqlDbType.VarChar, 10).Value = cboKhoa.SelectedValue;
   cmd.Parameters.Add("@DiemTB", SqlDbType.Decimal).Value = decimal.Parse(txtDiemTB.Text);
   cmd.Parameters.Add("@Email", SqlDbType.VarChar, 100).Value =
     string.IsNullOrWhiteSpace(txtEmail.Text) ? (object)DBNull.Value : txtEmail.Text;
   conn.Open();
   int rows = cmd.ExecuteNonQuery();
   MessageBox.Show("Đã thêm " + rows + " bản ghi.");
}

4. Cập nhật điểm bằng tham số

Yêu cầu: Cập nhật DiemTB theo MaSV; báo không tìm thấy khi rows = 0. Gợi ý triển khai: Không ghép mã sinh viên trực tiếp vào câu SQL.

string sql = "UPDATE SinhVien SET DiemTB=@DiemTB WHERE MaSV=@MaSV";
using (SqlConnection conn = DbConnectionFactory.Create())
using (SqlCommand cmd = new SqlCommand(sql, conn))
{
   SqlParameter pDiem = cmd.Parameters.Add("@DiemTB", SqlDbType.Decimal);
   pDiem.Precision = 4; pDiem.Scale = 2;
   pDiem.Value = decimal.Parse(txtDiemTB.Text);
   cmd.Parameters.Add("@MaSV", SqlDbType.VarChar, 15).Value = txtMaSV.Text.Trim();
   conn.Open();
   int rows = cmd.ExecuteNonQuery();
   MessageBox.Show(rows == 1 ? "Cập nhật thành công" : "Không tìm thấy mã");
}

5. Gọi Stored Procedure tìm sinh viên theo khoa

Yêu cầu: Tạo sp_SinhVien_TheoKhoa và gọi bằng CommandType.StoredProcedure.

Gợi ý triển khai: Tên tham số trong C# phải khớp thủ tục.

CREATE OR ALTER PROCEDURE sp_SinhVien_TheoKhoa
  @MaKhoa VARCHAR(10)
AS
BEGIN
  SET NOCOUNT ON;
  SELECT MaSV, HoTen, NgaySinh, DiemTB
  FROM SinhVien
  WHERE MaKhoa = @MaKhoa
  ORDER BY HoTen;
END;
GO
