Bài tập Chương 3 · WinForms và kiến trúc ba lớp.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Tạo ứng dụng Windows Forms và cấu hình thuộc tính Form.
  • Sử dụng Label, TextBox, Button, ComboBox, DateTimePicker, CheckBox, RadioButton và PictureBox.
  • Đặt tên điều khiển theo quy ước và bố trí giao diện dễ sử dụng.
  • Đọc dữ liệu từ control và hiển thị kết quả.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022 - Windows Forms App (.NET Framework 4.8).
  • Project Lab04_WinFormsBasic.
  • Ảnh đại diện mẫu định dạng PNG/JPG.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Chuyển mô hình SinhVien từ Console lên giao diện WinForms. Form nhập sinh viên sẽ được mở rộng sự kiện, kiểm tra dữ liệu và đa Form ở Lab 5.

4. Chuẩn bị trước khi thực hành

  • Tạo project Windows Forms App (.NET Framework) Lab04_WinFormsBasic.
  • Thêm lớp SinhVien.cs từ Lab 2 vào project.
  • Tạo thư mục Images và chuẩn bị 2-3 ảnh mẫu.

5. Bài tập có hướng dẫn và code mẫu

1. Tạo Form thông tin sinh viên

Yêu cầu: Thiết kế frmSinhVien gồm mã, họ tên, ngày sinh, giới tính, khoa và nút Hiển thị. Gợi ý triển khai: Quy ước tên: txtMaSV, txtHoTen, dtpNgaySinh, cboKhoa, btnHienThi.

private void btnHienThi_Click(object sender, EventArgs e)
{
  string gioiTinh = radNam.Checked ? "Nam" : "Nữ";
  string thongTin = string.Format(
     "Mã: {0}\nHọ tên: {1}\nNgày sinh: {2:dd/MM/yyyy}\nKhoa: {3}\nGiới tính: {4}",
     txtMaSV.Text, txtHoTen.Text, dtpNgaySinh.Value,
     cboKhoa.Text, gioiTinh);
  MessageBox.Show(thongTin, "Thông tin sinh viên");
}

2. Khởi tạo ComboBox và trạng thái Form

Yêu cầu: Nạp danh sách khoa khi Form Load; đặt khoa đầu tiên làm mặc định.

Gợi ý triển khai: Không nhập thủ công lại danh sách ở nhiều nơi.

private void frmSinhVien_Load(object sender, EventArgs e)
{
  cboKhoa.Items.Add("Công nghệ thông tin");
  cboKhoa.Items.Add("Công nghệ kỹ thuật ô tô");
  cboKhoa.Items.Add("Kinh tế");
  cboKhoa.DropDownStyle = ComboBoxStyle.DropDownList;
  if (cboKhoa.Items.Count > 0) cboKhoa.SelectedIndex = 0;
  radNam.Checked = true;
}

3. Tính tuổi từ DateTimePicker

Yêu cầu: Khi chọn ngày sinh, tính và hiển thị tuổi vào Label. Gợi ý triển khai: Xử lý trường hợp chưa đến ngày sinh trong năm hiện tại.

private int TinhTuoi(DateTime ngaySinh)
{
  int tuoi = DateTime.Today.Year - ngaySinh.Year;
  if (ngaySinh.Date > DateTime.Today.AddYears(-tuoi)) tuoi--;
  return tuoi;
}

private void dtpNgaySinh_ValueChanged(object sender, EventArgs e)
{
  lblTuoi.Text = "Tuổi: " + TinhTuoi(dtpNgaySinh.Value);
}

4. Sở thích bằng CheckBox

Yêu cầu: Dùng các CheckBox để chọn sở thích và hiển thị danh sách đã chọn. Gợi ý triển khai: Chỉ thêm mục khi Checked bằng true.

private void btnSoThich_Click(object sender, EventArgs e)
{
  List<string> ds = new List<string>();
  if (chkDocSach.Checked) ds.Add("Đọc sách");
  if (chkTheThao.Checked) ds.Add("Thể thao");
  if (chkLapTrinh.Checked) ds.Add("Lập trình");
  lblSoThich.Text = ds.Count == 0 ? "Chưa chọn" : string.Join(", ", ds);
}

5. Chọn ảnh đại diện

Yêu cầu: Dùng OpenFileDialog chọn ảnh và hiển thị trong PictureBox ở chế độ Zoom. Gợi ý triển khai: Kiểm tra đường dẫn tệp trước khi tải.

private void btnChonAnh_Click(object sender, EventArgs e)
{
  using (OpenFileDialog dlg = new OpenFileDialog())
  {
    dlg.Filter = "Image files|*.jpg;*.jpeg;*.png;*.bmp";
    if (dlg.ShowDialog() == DialogResult.OK)
    {
       picAnh.SizeMode = PictureBoxSizeMode.Zoom;
       picAnh.ImageLocation = dlg.FileName;
       txtDuongDanAnh.Text = dlg.FileName;
    }
  }
}
