Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Hiển thị và thao tác dữ liệu trên DataGridView, ListView và TreeView.
  • Sử dụng BindingList<T> hoặc BindingSource để liên kết dữ liệu trong bộ nhớ.
  • Tổ chức ứng dụng theo các lớp GUI, BUS và DAL giả lập.
  • Chuẩn bị kiến trúc để chuyển sang ADO.NET ở Lab 7.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022.
  • Project Lab06_ThreeLayerMemory.
  • Các lớp SinhVien và Khoa đã xây dựng.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Xây dựng phiên bản quản lý sinh viên chạy hoàn toàn trong bộ nhớ. Sang Lab 7, lớp DAL giả lập sẽ được thay bằng DAL kết nối SQL Server mà không thay đổi lớn giao diện.

4. Chuẩn bị trước khi thực hành

  • Sao chép mô hình SinhVien và các Form từ Lab 5.

  • Chuẩn bị dữ liệu mẫu theo ít nhất 3 khoa, mỗi khoa 3 sinh viên.

5. Bài tập có hướng dẫn và code mẫu

1. Hiển thị BindingList trên DataGridView

Yêu cầu: Tạo BindingList<SinhVien>, liên kết với DataGridView và cấu hình tiêu đề cột. Gợi ý triển khai: Tắt AutoGenerateColumns nếu muốn kiểm soát cột.

private BindingList<SinhVien> _ds = new BindingList<SinhVien>();

private void frmDanhSach_Load(object sender, EventArgs e)
{
  _ds.Add(new SinhVien("SV01", "Nguyễn An", DateTime.Today, 8.2));
  _ds.Add(new SinhVien("SV02", "Trần Bình", DateTime.Today, 7.0));
  dgvSinhVien.AutoGenerateColumns = true;
  dgvSinhVien.DataSource = _ds;
  dgvSinhVien.SelectionMode = DataGridViewSelectionMode.FullRowSelect;
}

2. CRUD trong bộ nhớ

Yêu cầu: Thêm, sửa, xóa sinh viên trong BindingList và đồng bộ giao diện.

Gợi ý triển khai: Kiểm tra trùng mã trước khi thêm.

private void btnThem_Click(object sender, EventArgs e)
{
  if (_ds.Any(x => x.MaSV == txtMaSV.Text.Trim()))
  {
     MessageBox.Show("Mã sinh viên đã tồn tại.");
     return;
  }
  _ds.Add(new SinhVien(txtMaSV.Text.Trim(), txtHoTen.Text.Trim(),
     dtpNgaySinh.Value, double.Parse(txtDiemTB.Text)));
}

private void btnXoa_Click(object sender, EventArgs e)
{
  SinhVien sv = dgvSinhVien.CurrentRow == null ? null
     : dgvSinhVien.CurrentRow.DataBoundItem as SinhVien;
  if (sv != null) _ds.Remove(sv);
}

3. Danh sách chi tiết bằng ListView

Yêu cầu: Hiển thị mã, họ tên, khoa, điểm trong ListView dạng Details. Gợi ý triển khai: Xóa Items trước khi nạp lại.

private void LoadListView(IEnumerable<SinhVien> data)
{
  lvSinhVien.Items.Clear();
  lvSinhVien.View = View.Details;
  foreach (SinhVien sv in data)
  {
    ListViewItem item = new ListViewItem(sv.MaSV);
    item.SubItems.Add(sv.HoTen);
    item.SubItems.Add(sv.DiemTB.ToString("N2"));
    item.Tag = sv;
    lvSinhVien.Items.Add(item);
  }
}

4. Cây Khoa - Sinh viên bằng TreeView

Yêu cầu: Tạo node gốc theo khoa và node con theo sinh viên; khi chọn node con hiển thị chi tiết. Gợi ý triển khai: Lưu đối tượng trong thuộc tính Tag của TreeNode.

private void LoadTree(Dictionary<string, List<SinhVien>> data)
{
  tvKhoa.Nodes.Clear();
  foreach (var group in data)
  {
    TreeNode khoaNode = new TreeNode(group.Key);
    foreach (SinhVien sv in group.Value)
    {
      TreeNode svNode = new TreeNode(sv.MaSV + " - " + sv.HoTen);
      svNode.Tag = sv;
      khoaNode.Nodes.Add(svNode);
    }
    tvKhoa.Nodes.Add(khoaNode);
  }
  tvKhoa.ExpandAll();
}

5. Tách mô hình GUI - BUS - DAL giả lập

Yêu cầu: Tạo SinhVienDAL lưu danh sách và SinhVienBUS kiểm tra nghiệp vụ; Form chỉ gọi BUS.

Gợi ý triển khai: Không để Form trực tiếp thao tác kho dữ liệu.

public class SinhVienDAL
{
  private readonly List<SinhVien> _data = new List<SinhVien>();
  public List<SinhVien> GetAll() { return new List<SinhVien>(_data); }
  public void Add(SinhVien sv) { _data.Add(sv); }
}

public class SinhVienBUS
{
  private readonly SinhVienDAL _dal = new SinhVienDAL();
  public List<SinhVien> GetAll() { return _dal.GetAll(); }
  public void Add(SinhVien sv)
  {
    if (string.IsNullOrWhiteSpace(sv.MaSV))
       throw new ArgumentException("Thiếu mã sinh viên");
    if (_dal.GetAll().Any(x => x.MaSV == sv.MaSV))
       throw new InvalidOperationException("Trùng mã sinh viên");
    _dal.Add(sv);
  }
}
