Bài tập Chương 2 · Lập trình hướng đối tượng với C#.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Khai báo lớp, trường dữ liệu, thuộc tính và phương thức trong C#.
  • Khởi tạo đối tượng bằng constructor mặc định và constructor có tham số.
  • Áp dụng đóng gói và kiểm tra dữ liệu tại thuộc tính.
  • Quản lý danh sách đối tượng bằng List<T>.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022.
  • Dự án Console Lab02_OOPBasics.
  • Kiến thức Lab 1 về nhập dữ liệu và xử lý ngoại lệ.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Xây dựng mô hình đối tượng SinhVien. Lớp này sẽ tiếp tục được mở rộng bằng kế thừa ở Lab 3 và đưa lên giao diện WinForms từ Lab 4.

4. Chuẩn bị trước khi thực hành

  • Sao chép Solution của Lab 1 và tạo project Lab02_OOPBasics.
  • Ôn lại phạm vi truy cập public, private và từ khóa this.
  • Chuẩn bị tối thiểu 5 bản ghi sinh viên để kiểm thử.

5. Bài tập có hướng dẫn và code mẫu

1. Khai báo lớp SinhVien

Yêu cầu: Tạo lớp SinhVien gồm MaSV, HoTen, NgaySinh và DiemTB; tạo một đối tượng và in thông tin. Gợi ý triển khai: Mỗi lớp đặt trong một tệp .cs riêng.

public class SinhVien
{
  public string MaSV { get; set; }
  public string HoTen { get; set; }
  public DateTime NgaySinh { get; set; }
  public double DiemTB { get; set; }

    public void HienThi()
    {
      Console.WriteLine("{0} - {1} - {2:dd/MM/yyyy} - {3:N2}",
        MaSV, HoTen, NgaySinh, DiemTB);
    }
}

2. Constructor và nạp chồng constructor

Yêu cầu: Bổ sung constructor không tham số và constructor đầy đủ tham số cho SinhVien. Gợi ý triển khai: Constructor phải bảo đảm đối tượng có trạng thái ban đầu hợp lệ.

public SinhVien()
{
  MaSV = "Chưa có";
  HoTen = "Chưa có";
  NgaySinh = DateTime.Today;
  DiemTB = 0;
}

public SinhVien(string maSV, string hoTen, DateTime ngaySinh, double diemTB)
{
  MaSV = maSV;
  HoTen = hoTen;
  NgaySinh = ngaySinh;
  DiemTB = diemTB;
}

3. Đóng gói và kiểm tra dữ liệu

Yêu cầu: Không cho phép DiemTB ngoài [0,10] và HoTen rỗng. Gợi ý triển khai: Dùng trường private làm backing field.

private string _hoTen;
private double _diemTB;

public string HoTen
{
  get { return _hoTen; }
  set
  {
    if (string.IsNullOrWhiteSpace(value))
       throw new ArgumentException("Họ tên không được rỗng.");
    _hoTen = value.Trim();
  }
}

public double DiemTB
{
  get { return _diemTB; }
  set
  {
    if (value < 0 || value > 10)
       throw new ArgumentOutOfRangeException("DiemTB");
    _diemTB = value;
  }
}

4. Phương thức nghiệp vụ của SinhVien

Yêu cầu: Viết phương thức TinhTuoi() và XepLoai() trả về kết quả tương ứng. Gợi ý triển khai: Không viết trực tiếp logic xếp loại trong Main().

public int TinhTuoi()
{
  int tuoi = DateTime.Today.Year - NgaySinh.Year;
  if (NgaySinh.Date > DateTime.Today.AddYears(-tuoi)) tuoi--;
  return tuoi;
}

  public string XepLoai()
  {
    if (DiemTB >= 9) return "Xuất sắc";
    if (DiemTB >= 8) return "Giỏi";
    if (DiemTB >= 6.5) return "Khá";
    if (DiemTB >= 5) return "Trung bình";
    return "Yếu";
  }

5. Quản lý danh sách SinhVien

Yêu cầu: Tạo List<SinhVien>, thêm dữ liệu mẫu, in danh sách và tìm theo mã. Gợi ý triển khai: Dùng foreach và phương thức Find hoặc vòng lặp.

List<SinhVien> ds = new List<SinhVien>();
ds.Add(new SinhVien("SV01", "Nguyễn An", new DateTime(2005, 5, 12), 8.2));
ds.Add(new SinhVien("SV02", "Trần Bình", new DateTime(2005, 9, 3), 6.8));

foreach (SinhVien sv in ds) sv.HienThi();
Console.Write("Mã cần tìm: ");
string ma = Console.ReadLine();
SinhVien ketQua = ds.Find(x => x.MaSV.Equals(ma,
   StringComparison.OrdinalIgnoreCase));
Console.WriteLine(ketQua == null ? "Không tìm thấy" : ketQua.HoTen);
