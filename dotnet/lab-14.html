Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Truyền tham số vào Crystal Report.
  • Nhóm dữ liệu, tạo tổng hợp và công thức trên báo cáo.
  • Thiết kế báo cáo theo khoa, khoảng điểm hoặc học kỳ.
  • Xuất báo cáo và dữ liệu sang Excel.

2. Công cụ và dữ liệu chuẩn bị

  • Crystal Reports và runtime.
  • CSDL QLSinhVien.
  • Project Lab14_AdvancedReport.
  • Microsoft Excel hoặc phần mềm đọc XLS/XLSX.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Nâng cấp báo cáo cơ bản ở Lab 13 thành báo cáo phục vụ quản lý. Kết quả được tích hợp vào ứng dụng tổng hợp ở Lab 16.

5. Bài tập có hướng dẫn và code mẫu

1. Báo cáo theo tham số khoa

Yêu cầu: Chọn khoa trên Form, lấy dữ liệu theo khoa và truyền tên khoa vào tiêu đề báo cáo. Gợi ý triển khai: Có thể lọc tại SQL hoặc RecordSelectionFormula; ưu tiên truy vấn tham số hóa.

DataTable data = _dal.GetStudentsByDepartment(maKhoa);
ReportDocument report = new CrystalReportSinhVienTheoKhoa();
report.SetDataSource(data);
report.SetParameterValue("pTenKhoa", cboKhoa.Text);

crystalReportViewer1.ReportSource = report;

2. Nhóm dữ liệu theo khoa

Yêu cầu: Trong Report Designer, Group theo TenKhoa; hiển thị tiêu đề nhóm và số sinh viên mỗi nhóm. Gợi ý triển khai: Dùng Insert Group và Summary Count(MaSV).

// Công thức gợi ý trong Crystal Formula Workshop:

3. Thống kê điểm trung bình và xếp loại

Yêu cầu: Hiển thị Average(DiemTB), Max, Min theo khoa; tạo công thức xếp loại. Gợi ý triển khai: Định dạng số với 2 chữ số thập phân.

// Formula @XepLoai
If {SinhVienReport.DiemTB} >= 9 Then "Xuất sắc"
Else If {SinhVienReport.DiemTB} >= 8 Then "Giỏi"
Else If {SinhVienReport.DiemTB} >= 6.5 Then "Khá"
Else If {SinhVienReport.DiemTB} >= 5 Then "Trung bình"
Else "Yếu"

4. Báo cáo theo khoảng điểm

Yêu cầu: Nhập điểm min/max trên Form, lọc dữ liệu và truyền khoảng điểm vào phần tiêu đề. Gợi ý triển khai: Kiểm tra min <= max và đều thuộc [0,10].

public DataTable GetByScoreRange(decimal min, decimal max)
{
  const string sql = @"SELECT * FROM vw_BaoCaoSinhVien
                WHERE DiemTB BETWEEN @Min AND @Max
                ORDER BY DiemTB DESC";
  using (SqlConnection conn = DbConnectionFactory.Create())
  using (SqlDataAdapter ad = new SqlDataAdapter(sql, conn))
  {
    ad.SelectCommand.Parameters.Add("@Min", SqlDbType.Decimal).Value = min;
    ad.SelectCommand.Parameters.Add("@Max", SqlDbType.Decimal).Value = max;
    DataTable t = new DataTable("SinhVienReport");
    ad.Fill(t); return t;
  }
}

5. Xuất Crystal Report sang Excel

Yêu cầu: Xuất báo cáo hiện tại sang định dạng Excel Workbook. Gợi ý triển khai: Kiểm tra tệp không đang mở trong Excel.

private void btnXuatExcel_Click(object sender, EventArgs e)
{
  using (SaveFileDialog dlg = new SaveFileDialog())
  {
    dlg.Filter = "Excel Workbook|*.xls";
    dlg.FileName = "BaoCaoSinhVien.xls";
    if (dlg.ShowDialog() == DialogResult.OK)
    {
       _report.ExportToDisk(ExportFormatType.ExcelWorkbook, dlg.FileName);
       MessageBox.Show("Đã xuất Excel.");
    }
  }
}
