Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Tích hợp mô hình 3 lớp, ADO.NET, CRUD, Stored Procedure và Transaction.
  • Xây dựng giao diện đa Form, master-detail, tìm kiếm và báo cáo.
  • Áp dụng kiểm tra dữ liệu, logging, cấu hình và đóng gói.
  • Hoàn thiện sản phẩm có thể trình diễn, cài đặt và bàn giao.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022.
  • SQL Server/SSMS.
  • Crystal Reports runtime.
  • Git hoặc cơ chế quản lý phiên bản.
  • Tài liệu và mã nguồn từ Lab 1-15.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Lab tổng hợp kết nối toàn bộ kiến thức. Nhóm có thể chọn Quản lý sinh viên hoặc một nghiệp vụ quản lý tương đương, nhưng phải đáp ứng đầy đủ chuẩn kỹ thuật trong rubric.

4. Chuẩn bị trước khi thực hành

  • Chọn nghiệp vụ và chốt phạm vi chức năng trước buổi lab.
  • Tạo repository Git hoặc cơ chế sao lưu theo phiên bản.
  • Phân công nhiệm vụ nếu làm theo nhóm; thống nhất quy ước mã nguồn.

5. Bài tập có hướng dẫn và code mẫu

1. Khởi tạo Solution và kiến trúc

Yêu cầu: Tạo solution gồm GUI, BUS, DAL và DTO; cấu hình tham chiếu đúng chiều. Gợi ý triển khai: GUI -> BUS -> DAL; DTO được dùng chung. DAL không tham chiếu GUI.

QLSinhVien.sln
|-- QLSinhVien.DTO       // SinhVienDTO, KhoaDTO, HocPhanDTO, DangKyDTO
|-- QLSinhVien.DAL       // Connection, repository, transaction
|-- QLSinhVien.BUS      // Validation và nghiệp vụ
|-- QLSinhVien.GUI      // WinForms, Crystal Report, App.config
|-- Database       // SQL script và Stored Procedure
|-- Docs        // Hướng dẫn cài đặt, tài khoản thử, kiểm thử

2. Khởi tạo CSDL và Stored Procedure

Yêu cầu: Tạo script chạy từ đầu gồm bảng, khóa, dữ liệu mẫu, view, Stored Procedure CRUD và báo cáo.

Gợi ý triển khai: Script phải idempotent ở mức hợp lý hoặc có hướng dẫn chạy mới rõ ràng.

3. Hoàn thiện CRUD và tìm kiếm

Yêu cầu: Thực hiện CRUD cho ít nhất 3 danh mục; tìm kiếm đa tiêu chí, phân trang hoặc sắp xếp. Gợi ý triển khai: Tất cả câu lệnh phải tham số hóa hoặc dùng Stored Procedure.

4. Nghiệp vụ nhiều bảng và Transaction

Yêu cầu: Cài đặt ít nhất một chức năng transaction: thêm sinh viên kèm đăng ký, chuyển khoa, lập phiếu hoặc cập nhật hàng loạt. Gợi ý triển khai: Có kịch bản thử Commit và Rollback.

public void RegisterStudent(SinhVienDTO student, List<DangKyDTO> courses)
{
  using (SqlConnection conn = DbConnectionFactory.Create())
  {
    conn.Open();
    SqlTransaction tx = conn.BeginTransaction();
    try
    {
       _studentDal.Insert(student, conn, tx);
       foreach (DangKyDTO item in courses)
         _enrollmentDal.Insert(item, conn, tx);
       tx.Commit();
    }
    catch
    {
       tx.Rollback();
       throw;
    }
  }
}
