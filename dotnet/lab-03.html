Lab 3. Kế thừa, đa hình, lớp trừu tượng và interface

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Mô hình hóa quan hệ kế thừa và sử dụng từ khóa base.
  • Ghi đè phương thức bằng virtual/override và khai thác đa hình.
  • Thiết kế lớp trừu tượng và interface.
  • Vận dụng nguyên lý OOP vào bài toán quản lý.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022.
  • Dự án Console Lab03_OOPAdvanced.
  • Lớp SinhVien từ Lab 2.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Mở rộng mô hình người học thành hệ thống nhiều loại đối tượng. Các interface kiểm tra dữ liệu và hiển thị sẽ được tái sử dụng ở tầng BUS trong các lab sau.

4. Chuẩn bị trước khi thực hành

  • Hoàn thiện lớp SinhVien của Lab 2.
  • Vẽ sơ đồ lớp đơn giản cho Nguoi, SinhVien và NguoiHoc.
  • Ôn từ khóa virtual, override, abstract, interface và base.

5. Bài tập có hướng dẫn và code mẫu

1. Kế thừa Nguoi - SinhVien

Yêu cầu: Tạo lớp cơ sở Nguoi và lớp SinhVien kế thừa; gọi constructor lớp cha bằng base. Gợi ý triển khai: Đưa HoTen, NgaySinh lên lớp Nguoi.

   public class Nguoi
   {
     public string HoTen { get; set; }
     public DateTime NgaySinh { get; set; }

       public Nguoi(string hoTen, DateTime ngaySinh)
       {
         HoTen = hoTen;
         NgaySinh = ngaySinh;
       }
   }

   public class SinhVien : Nguoi

{
    public string MaSV { get; set; }
    public double DiemTB { get; set; }

    public SinhVien(string ma, string ten, DateTime ngaySinh, double diem)
      : base(ten, ngaySinh)
    {
      MaSV = ma;
      DiemTB = diem;
    }
}

2. Ghi đè phương thức hiển thị

Yêu cầu: Khai báo phương thức MoTa() ảo ở Nguoi và ghi đè trong SinhVien. Gợi ý triển khai: Gọi base.MoTa() khi cần tái sử dụng hành vi lớp cha.

public class Nguoi
{
  public virtual string MoTa()
  {
    return HoTen + " - " + NgaySinh.ToString("dd/MM/yyyy");
  }
}

public class SinhVien : Nguoi
{
  public override string MoTa()
  {
    return base.MoTa() + " - " + MaSV + " - " + DiemTB.ToString("N2");
  }
}

3. Lớp trừu tượng HocPhi

Yêu cầu: Tạo lớp trừu tượng NguoiHoc có phương thức TinhHocPhi(); cài đặt SinhVienChinhQuy và SinhVienLienThong. Gợi ý triển khai: Mỗi loại người học có công thức học phí khác nhau.

public abstract class NguoiHoc
{
  public string HoTen { get; set; }
  public int SoTinChi { get; set; }
  public abstract decimal TinhHocPhi();
}

public class SinhVienChinhQuy : NguoiHoc
{
  public override decimal TinhHocPhi()
  {
    return SoTinChi * 450000m;
  }
}

public class SinhVienLienThong : NguoiHoc
{
  public override decimal TinhHocPhi()
  {
    return SoTinChi * 520000m;
  }
}

4. Interface kiểm tra và in dữ liệu

Yêu cầu: Tạo IValidatable và IPrintable; cho SinhVien thực thi cả hai interface. Gợi ý triển khai: Interface chỉ khai báo hợp đồng, lớp cài đặt nội dung.

public interface IValidatable
{
  bool IsValid(out string message);
}

public interface IPrintable
{
  string ToDisplayText();
}

public class SinhVien : IValidatable, IPrintable
{
  public string MaSV { get; set; }
  public string HoTen { get; set; }
  public double DiemTB { get; set; }

    public bool IsValid(out string message)
    {
      if (string.IsNullOrWhiteSpace(MaSV)) { message = "Thiếu mã"; return false; }
      if (DiemTB < 0 || DiemTB > 10) { message = "Điểm sai"; return false; }
      message = ""; return true;
    }
    public string ToDisplayText() { return MaSV + " - " + HoTen; }
}

5. Danh sách đa hình

Yêu cầu: Tạo List<NguoiHoc> chứa nhiều kiểu sinh viên và tính tổng học phí. Gợi ý triển khai: Gọi phương thức qua tham chiếu lớp cha để thể hiện đa hình.

List<NguoiHoc> ds = new List<NguoiHoc>();
ds.Add(new SinhVienChinhQuy { HoTen = "An", SoTinChi = 18 });
ds.Add(new SinhVienLienThong { HoTen = "Bình", SoTinChi = 15 });

decimal tong = 0;
foreach (NguoiHoc item in ds)
{
  decimal hocPhi = item.TinhHocPhi();
  tong += hocPhi;
  Console.WriteLine("{0}: {1:N0}", item.HoTen, hocPhi);
}
Console.WriteLine("Tổng học phí: {0:N0}", tong);
