Bài tập Chương 3 · WinForms và kiến trúc ba lớp.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Lập trình các sự kiện Click, TextChanged, KeyPress, SelectedIndexChanged và FormClosing.
  • Kiểm tra dữ liệu bằng ErrorProvider và các hàm dùng chung.
  • Truyền dữ liệu giữa các Form bằng constructor, thuộc tính hoặc delegate/event.
  • Tổ chức ứng dụng nhiều Form với MenuStrip.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio 2022.
  • Project Lab05_MultiForm kế thừa giao diện Lab 4.
  • ErrorProvider, MenuStrip và StatusStrip.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Hoàn thiện luồng nhập - xem chi tiết - danh sách sinh viên. Sang Lab 6, dữ liệu sẽ được hiển thị bằng DataGridView và tổ chức theo mô hình 3 lớp trong bộ nhớ.

4. Chuẩn bị trước khi thực hành

  • Hoàn thiện frmSinhVien từ Lab 4.
  • Tạo thêm frmMain, frmChiTietSinhVien và frmGioiThieu.
  • Ôn các kiểu truyền dữ liệu giữa Form.

5. Bài tập có hướng dẫn và code mẫu

1. Kiểm tra bắt buộc bằng ErrorProvider

Yêu cầu: Không cho lưu khi mã hoặc họ tên trống; hiển thị lỗi cạnh control. Gợi ý triển khai: Tách kiểm tra thành phương thức ValidateInput().

   private bool ValidateInput()
   {
     errorProvider1.Clear();
     bool valid = true;
     if (string.IsNullOrWhiteSpace(txtMaSV.Text))
     {
        errorProvider1.SetError(txtMaSV, "Nhập mã sinh viên");
        valid = false;
     }
     if (string.IsNullOrWhiteSpace(txtHoTen.Text))
     {
        errorProvider1.SetError(txtHoTen, "Nhập họ tên");
        valid = false;

    }
    return valid;
}

2. Giới hạn ký tự nhập điểm

Yêu cầu: Chỉ cho phép nhập chữ số và một dấu thập phân vào txtDiemTB. Gợi ý triển khai: Vẫn phải kiểm tra miền [0,10] khi lưu.

private void txtDiemTB_KeyPress(object sender, KeyPressEventArgs e)
{
  if (char.IsControl(e.KeyChar)) return;
  if (char.IsDigit(e.KeyChar)) return;
  if (e.KeyChar == '.' && !txtDiemTB.Text.Contains(".")) return;
  e.Handled = true;
}

3. Cập nhật trạng thái theo thời gian thực

Yêu cầu: Khi họ tên hoặc điểm thay đổi, cập nhật Label xem trước và trạng thái hợp lệ. Gợi ý triển khai: Dùng chung một handler cho nhiều TextBox.

private void Input_TextChanged(object sender, EventArgs e)
{
  double diem;
  bool hopLe = double.TryParse(txtDiemTB.Text, out diem)
          && diem >= 0 && diem <= 10;
  lblXemTruoc.Text = txtMaSV.Text + " - " + txtHoTen.Text;
  lblTrangThai.Text = hopLe ? "Dữ liệu điểm hợp lệ" : "Kiểm tra điểm";
}

4. Truyền dữ liệu sang Form chi tiết

Yêu cầu: Tạo frmChiTietSinhVien nhận đối tượng SinhVien qua constructor và hiển thị dữ liệu. Gợi ý triển khai: Không truy cập trực tiếp control private của Form khác.

public partial class frmChiTietSinhVien : Form
{
  private readonly SinhVien _sinhVien;

    public frmChiTietSinhVien(SinhVien sinhVien)
    {
      InitializeComponent();
      _sinhVien = sinhVien;
    }

    private void frmChiTietSinhVien_Load(object sender, EventArgs e)
    {
      lblMa.Text = _sinhVien.MaSV;
      lblHoTen.Text = _sinhVien.HoTen;
      lblDiem.Text = _sinhVien.DiemTB.ToString("N2");
    }
}

5. MenuStrip mở các Form chức năng

Yêu cầu: Tạo frmMain có menu Danh mục, Nghiệp vụ, Hệ thống; mở Form con và tránh mở trùng. Gợi ý triển khai: Có thể dùng MDI hoặc mở Form modal tùy chức năng.

private void OpenChildForm(Form child)
{
  foreach (Form f in this.MdiChildren)
  {
    if (f.GetType() == child.GetType())

        {
            f.Activate();
            child.Dispose();
            return;
        }
      }
      child.MdiParent = this;
      child.Show();
  }

  private void mnuSinhVien_Click(object sender, EventArgs e)
  {
    OpenChildForm(new frmSinhVien());
  }
