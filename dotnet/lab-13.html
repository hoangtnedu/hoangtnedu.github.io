Bài tập Chương 5 · Báo cáo Crystal Reports và Excel.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

Dùng tiêu đề cá nhân HoangTN hoặc tiêu đề trung tính khi thiết kế báo cáo.

1. Mục tiêu cần đạt được

  • Cài đặt và cấu hình Crystal Reports cho Visual Studio.
  • Tạo nguồn dữ liệu DataSet cho báo cáo.
  • Thiết kế báo cáo danh sách sinh viên cơ bản.
  • Hiển thị báo cáo trong CrystalReportViewer và xuất PDF.

2. Công cụ và dữ liệu chuẩn bị

  • Visual Studio tương thích SAP Crystal Reports.
  • SAP Crystal Reports for Visual Studio và runtime phù hợp.
  • CSDL QLSinhVien và project Lab13_CrystalReport.
  • CrystalReportViewer.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Sử dụng dữ liệu của ứng dụng quản lý sinh viên đã hoàn thiện ở Lab 12. Lab 14 sẽ bổ sung tham số, nhóm, thống kê và xuất Excel.

4. Chuẩn bị trước khi thực hành

  • Cài Crystal Reports và runtime trước buổi học.
  • Kiểm tra project ở nền tảng x86 hoặc x64 phù hợp.
  • Chuẩn bị tiêu đề cá nhân HoangTN và dữ liệu tối thiểu 20 sinh viên.

5. Bài tập có hướng dẫn và code mẫu

1. Kiểm tra môi trường Crystal Reports

Yêu cầu: Xác nhận project có mục Crystal Report và có thể kéo CrystalReportViewer lên Form. Gợi ý triển khai: Chọn đúng kiến trúc x86/x64 tương thích runtime.

// Kiểm tra các namespace sau được nhận diện sau khi cài đặt:
using CrystalDecisions.CrystalReports.Engine;
using CrystalDecisions.Shared;
using CrystalDecisions.Windows.Forms;

2. Tạo truy vấn nguồn báo cáo

Yêu cầu: Tạo view vw_BaoCaoSinhVien chứa sinh viên và tên khoa. Gợi ý triển khai: View giúp báo cáo dùng nguồn dữ liệu ổn định.

  CREATE OR ALTER VIEW vw_BaoCaoSinhVien
  AS

SELECT sv.MaSV, sv.HoTen, sv.NgaySinh,
   CASE sv.GioiTinh WHEN 1 THEN N'Nam' ELSE N'Nữ' END AS GioiTinh,
   k.MaKhoa, k.TenKhoa, sv.DiemTB, sv.Email
FROM SinhVien sv
JOIN Khoa k ON sv.MaKhoa = k.MaKhoa;
GO

3. Tạo DataTable cho báo cáo

Yêu cầu: Viết hàm lấy dữ liệu từ view để làm nguồn cho báo cáo. Gợi ý triển khai: Tên cột phải khớp thiết kế Crystal Report.

public DataTable GetStudentReportData()
{
  DataTable table = new DataTable("SinhVienReport");
  using (SqlConnection conn = DbConnectionFactory.Create())
  using (SqlDataAdapter adapter = new SqlDataAdapter(
    "SELECT * FROM vw_BaoCaoSinhVien ORDER BY TenKhoa, HoTen", conn))
  {
    adapter.Fill(table);
  }
  return table;
}

4. Hiển thị báo cáo trên CrystalReportViewer

Yêu cầu: Nạp DataTable vào report .rpt và hiển thị trong frmBaoCaoSinhVien. Gợi ý triển khai: Tên lớp report thay đổi theo tên tệp .rpt trong project.

private ReportDocument _report;

private void frmBaoCaoSinhVien_Load(object sender, EventArgs e)
{
  DataTable data = new BaoCaoDAL().GetStudentReportData();
  _report = new CrystalReportSinhVien();
  _report.SetDataSource(data);
  crystalReportViewer1.ReportSource = _report;
  crystalReportViewer1.Refresh();
}

protected override void OnFormClosed(FormClosedEventArgs e)
{
  if (_report != null) { _report.Close(); _report.Dispose(); }
  base.OnFormClosed(e);
}

5. Xuất báo cáo ra PDF

Yêu cầu: Cho phép người dùng chọn vị trí lưu và xuất báo cáo hiện tại sang PDF. Gợi ý triển khai: Báo cáo phải được SetDataSource trước khi xuất.

private void btnXuatPdf_Click(object sender, EventArgs e)
{
  using (SaveFileDialog dlg = new SaveFileDialog())
  {
    dlg.Filter = "PDF file|*.pdf";
    dlg.FileName = "DanhSachSinhVien.pdf";
    if (dlg.ShowDialog() == DialogResult.OK)
    {
       _report.ExportToDisk(ExportFormatType.PortableDocFormat, dlg.FileName);
       MessageBox.Show("Đã xuất báo cáo.");
    }
  }
}
