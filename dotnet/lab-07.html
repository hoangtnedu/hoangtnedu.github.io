Lab 7. Tạo CSDL SQL Server, tổng quan ADO.NET và kết nối

Bài tập Chương 4 · Truy cập dữ liệu với ADO.NET.

Đọc lý thuyết liên quan →

Mã mẫu minh họa từng bài, có thể cần ghép với lớp, Form hoặc CSDL ở lab trước. Không dán tất cả ví dụ cùng tên lớp vào một tệp. Chuỗi desktop dùng .NET Framework 4.8; chuẩn bị runtime Crystal Reports tương thích cho Lab 13–16.

1. Mục tiêu cần đạt được

  • Tạo cơ sở dữ liệu quan hệ cho bài toán quản lý sinh viên.
  • Thiết lập khóa chính, khóa ngoại, ràng buộc và dữ liệu mẫu.
  • Hiểu vai trò của Connection trong ADO.NET.
  • Tạo lớp kết nối SQL Server và kiểm tra trạng thái kết nối.

2. Công cụ và dữ liệu chuẩn bị

  • SQL Server 2019/2022 hoặc SQL Server Express.
  • SQL Server Management Studio.
  • Visual Studio 2022 - System.Data.SqlClient.
  • Project Lab07_ADONET_Connection.

3. Liên kết trong chuỗi bài lab

Ngữ cảnh xuyên suốt: Thay lớp DAL lưu trong bộ nhớ ở Lab 6 bằng SQL Server. Cơ sở dữ liệu QLSinhVien được sử dụng liên tục từ Lab 7 đến Lab 16.

4. Chuẩn bị trước khi thực hành

  • Cài SQL Server và SSMS; xác định tên instance.
  • Bật quyền kết nối phù hợp và tạo database thử.
  • Tạo project Lab07_ADONET_Connection, tham chiếu System.Configuration nếu dùng App.config.

5. Bài tập có hướng dẫn và code mẫu

1. Tạo cơ sở dữ liệu QLSinhVien

Yêu cầu: Tạo database và chuyển ngữ cảnh sử dụng sang QLSinhVien. Gợi ý triển khai: Chạy từng khối lệnh và ghi nhận kết quả trong SSMS.

IF DB_ID(N'QLSinhVien') IS NULL
  CREATE DATABASE QLSinhVien;
GO
USE QLSinhVien;
GO

2. Tạo bảng Khoa và SinhVien

Yêu cầu: Tạo bảng có khóa chính, khóa ngoại và CHECK điểm thuộc [0,10]. Gợi ý triển khai: Dùng kiểu NVARCHAR cho dữ liệu tiếng Việt.

  CREATE TABLE Khoa

(
     MaKhoa VARCHAR(10) PRIMARY KEY,
     TenKhoa NVARCHAR(100) NOT NULL UNIQUE
);

CREATE TABLE SinhVien
(
   MaSV VARCHAR(15) PRIMARY KEY,
   HoTen NVARCHAR(100) NOT NULL,
   NgaySinh DATE NOT NULL,
   GioiTinh BIT NOT NULL,
   MaKhoa VARCHAR(10) NOT NULL,
   DiemTB DECIMAL(4,2) NOT NULL DEFAULT 0,
   Email VARCHAR(100) NULL,
   CONSTRAINT CK_SinhVien_Diem CHECK (DiemTB BETWEEN 0 AND 10),
   CONSTRAINT FK_SinhVien_Khoa FOREIGN KEY (MaKhoa) REFERENCES Khoa(MaKhoa)
);

3. Tạo bảng HocPhan và DangKy

Yêu cầu: Mô hình hóa quan hệ nhiều-nhiều giữa SinhVien và HocPhan. Gợi ý triển khai: Khóa chính của DangKy gồm MaSV và MaHP.

CREATE TABLE HocPhan
(
   MaHP VARCHAR(10) PRIMARY KEY,
   TenHP NVARCHAR(120) NOT NULL,
   SoTinChi INT NOT NULL CHECK (SoTinChi BETWEEN 1 AND 6)
);

CREATE TABLE DangKy
(
   MaSV VARCHAR(15) NOT NULL,
   MaHP VARCHAR(10) NOT NULL,
   HocKy INT NOT NULL CHECK (HocKy BETWEEN 1 AND 3),
   Diem DECIMAL(4,2) NULL CHECK (Diem BETWEEN 0 AND 10),
   PRIMARY KEY (MaSV, MaHP),
   FOREIGN KEY (MaSV) REFERENCES SinhVien(MaSV),
   FOREIGN KEY (MaHP) REFERENCES HocPhan(MaHP)
);

4. Thêm dữ liệu mẫu

Yêu cầu: Thêm tối thiểu 3 khoa, 10 sinh viên, 5 học phần và dữ liệu đăng ký. Gợi ý triển khai: Dùng tiền tố N trước chuỗi Unicode.

5. Tạo lớp kết nối SQL Server

Yêu cầu: Viết lớp DbConnectionFactory và nút Kiểm tra kết nối trên Form. Gợi ý triển khai: Thay tên máy chủ theo môi trường thực tế; luôn đóng kết nối.

using System.Data.SqlClient;

public static class DbConnectionFactory

  {
      private const string ConnectionString =
        @"Data Source=.;Initial Catalog=QLSinhVien;Integrated Security=True";

      public static SqlConnection Create()
      {
        return new SqlConnection(ConnectionString);
      }
  }

  private void btnKiemTra_Click(object sender, EventArgs e)
  {
    try
    {
      using (SqlConnection conn = DbConnectionFactory.Create())
      {
        conn.Open();
        MessageBox.Show("Kết nối thành công: " + conn.Database);
      }
    }
    catch (SqlException ex)
    {
      MessageBox.Show("Lỗi kết nối: " + ex.Message);
    }
  }

6. Bài tập tự thực hiện - không có code gợi ý

6. Bổ sung ràng buộc dữ liệu

Yêu cầu: Thêm UNIQUE Email, DEFAULT ngày đăng ký và CHECK học kỳ; thử dữ liệu vi phạm.

7. Chuỗi kết nối SQL Authentication

Yêu cầu: Tạo tài khoản SQL riêng cho ứng dụng, cấp quyền tối thiểu và kiểm tra kết nối.

8. Đọc chuỗi kết nối từ App.config

Yêu cầu: Không hard-code chuỗi kết nối trong mã nguồn; sử dụng ConfigurationManager.

9. Trang trạng thái kết nối

Yêu cầu: Hiển thị DataSource, Database, ServerVersion, State và thời gian kết nối.

10. Sao lưu và phục hồi CSDL

Yêu cầu: Thực hiện backup QLSinhVien, xóa một bản ghi thử và restore để kiểm chứng.

  • Project WinForms có chức năng kiểm tra kết nối.
  • Ảnh sơ đồ quan hệ CSDL và kết quả truy vấn dữ liệu mẫu.
