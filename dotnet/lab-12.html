  • Rollback khi một bước thất bại.
  • Hoàn thiện luồng GUI - BUS - DAL cho chức năng liên quan nhiều bảng.

2. Công cụ và dữ liệu chuẩn bị

5. Bài tập có hướng dẫn và code mẫu

1. Giao diện master-detail Khoa - SinhVien

Yêu cầu: Khi chọn một khoa ở lưới trên, lưới dưới chỉ hiển thị sinh viên thuộc khoa đó. Gợi ý triển khai: Tải danh sách con bằng truy vấn tham số hoặc BindingSource quan hệ.

private void dgvKhoa_SelectionChanged(object sender, EventArgs e)
{
  if (dgvKhoa.CurrentRow == null) return;

2. Master-detail SinhVien - Đăng ký học phần

Yêu cầu: Hiển thị các học phần đã đăng ký khi chọn sinh viên; cho phép thêm đăng ký. Gợi ý triển khai: Dùng JOIN để hiển thị tên học phần.

SELECT dk.MaSV, dk.MaHP, hp.TenHP, hp.SoTinChi, dk.HocKy, dk.Diem
FROM DangKy dk
JOIN HocPhan hp ON dk.MaHP = hp.MaHP
WHERE dk.MaSV = @MaSV
ORDER BY dk.HocKy, hp.TenHP;

3. Transaction thêm sinh viên và đăng ký

Yêu cầu: Trong một giao dịch, thêm sinh viên rồi thêm danh sách học phần đăng ký ban đầu. Gợi ý triển khai: Gán cùng Connection và Transaction cho mọi SqlCommand.

using (SqlConnection conn = DbConnectionFactory.Create())
{
  conn.Open();
  SqlTransaction tx = conn.BeginTransaction();
  try
  {
    using (SqlCommand cmdSv = new SqlCommand(sqlInsertSinhVien, conn, tx))
    {
       // Thêm tham số sinh viên
       cmdSv.ExecuteNonQuery();
    }
    foreach (DangKyDTO dk in danhSachDangKy)
    {
       using (SqlCommand cmdDk = new SqlCommand(sqlInsertDangKy, conn, tx))
       {
          cmdDk.Parameters.Add("@MaSV", SqlDbType.VarChar, 15).Value = dto.MaSV;
          cmdDk.Parameters.Add("@MaHP", SqlDbType.VarChar, 10).Value = dk.MaHP;
          cmdDk.Parameters.Add("@HocKy", SqlDbType.Int).Value = dk.HocKy;
          cmdDk.ExecuteNonQuery();
       }
    }
    tx.Commit();
  }
  catch
  {
    tx.Rollback();
    throw;
  }
}

5. Hoàn thiện lớp DAL dùng transaction

Yêu cầu: Cho phép các phương thức DAL nhận SqlConnection và SqlTransaction từ bên ngoài khi tham gia giao dịch. Gợi ý triển khai: BUS điều phối nghiệp vụ; DAL chỉ thực thi dữ liệu.

public void InsertEnrollment(DangKyDTO dto,
  SqlConnection conn, SqlTransaction tx)
{
  const string sql = @"INSERT INTO DangKy(MaSV,MaHP,HocKy,Diem)
              VALUES(@MaSV,@MaHP,@HocKy,@Diem)";
  using (SqlCommand cmd = new SqlCommand(sql, conn, tx))
  {
    cmd.Parameters.Add("@MaSV", SqlDbType.VarChar, 15).Value = dto.MaSV;
    cmd.Parameters.Add("@MaHP", SqlDbType.VarChar, 10).Value = dto.MaHP;
    cmd.Parameters.Add("@HocKy", SqlDbType.Int).Value = dto.HocKy;
    cmd.Parameters.Add("@Diem", SqlDbType.Decimal).Value =
       dto.Diem.HasValue ? (object)dto.Diem.Value : DBNull.Value;
    cmd.ExecuteNonQuery();
  }
}
