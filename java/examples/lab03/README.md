# Lab 3: Java Swing: giao diện và xử lý sự kiện

Nội dung và bài tập: https://hoangtnedu.github.io/java/lab-03.html

Mã mẫu thực thi đã biên tập từ các chức năng có hướng dẫn. Các bài tự làm
vẫn được giữ trong trang học liệu để người học tự hoàn thiện.

Build: `mvn clean verify` tại thư mục này (cần JDK 17/21, Maven và POM cha
ở thư mục examples đối với Lab 2–10). Linux cần Xvfb cho kiểm thử Swing.
Sản phẩm JAR nằm trong target. Xem README chung ở ../README.md để cấu hình
DB_URL, tài khoản demo, server và lệnh chạy.

CI kiểm tra trên JDK 17 và 21. Không đồng nhất build thành công với việc hoàn thành
tất cả chức năng tự làm hoặc kiểm thử giao diện thủ công.
