Chuẩn bị trước khi học

Nắm biến, điều kiện, vòng lặp, lớp và SQL cơ bản. Java SE dùng JDK 17 hoặc 21 và Maven 3.x. Phần Jakarta EE chọn runtime Web Profile tương thích; phần Spring dùng project riêng theo cấu hình Boot 3.5.x được nêu trong bài. Các ví dụ Java chạy trên máy người học.
