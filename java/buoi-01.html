Buổi 1. Nền tảng Java và môi trường thực thi

Trần Nguyên HoàngCập nhật 27/10/2026
Trong bài này
  1. Nội dung theo lịch trình
  2. Trọng tâm cần hiểu
  3. Các bước thực hiện
  4. Kiểm tra kết quả
  5. Sản phẩm cần đạt

  7. Đọc và thực hành liên quan

Năm bài tập Lab 1 lấy từ tệp lab được cung cấp; xem hướng dẫn đầy đủ và mã nguồn.

Nội dung theo lịch trình

Giới thiệu học phần. Lịch sử Java; Java Platform: Java SE, Jakarta EE, Java ME; JVM, JIT, JDK, JRE.

Hình thức: Lý thuyết. Hoạt động: Giảng lý thuyết, minh họa vai trò Java trong phát triển ứng dụng.

Trọng tâm cần hiểu

Bắt đầu từ một chương trình in thông báo, xác định công cụ tạo ra bytecode và công cụ thực thi. So sánh ứng dụng Console với ứng dụng doanh nghiệp để chọn đúng nền tảng. Điểm cần hiểu là mã nguồn, bytecode và JVM có vai trò riêng.

Các bước thực hiện

  • Cài JDK và IDE, tạo App có main, biên dịch rồi chạy bằng terminal.
  • Thay đổi thông báo và cố ý tạo lỗi cú pháp để phân biệt lỗi biên dịch với lỗi chạy.
  • Viết bảng giải thích Java SE, Jakarta EE, Java ME, JDK, JRE, JVM và JIT.

Kiểm tra kết quả

Đổi tên lớp nhưng giữ nguyên tên tệp; dùng sai package; quan sát lỗi và sửa lại.

Sản phẩm cần đạt

Theo lịch trình gốc: Cài JDK, IDE. Viết chương trình Java đơn giản.

Gói thực hành: Bản giải thích môi trường, ảnh java/javac và chương trình chạy được.

Tự giải thích sau buổi học

  • Mô tả luồng dữ liệu của chức năng vừa làm và chỉ ra lớp chịu trách nhiệm từng bước.
  • Nêu một ca lỗi đã thử, kết quả thực tế và cách khắc phục.
  • Ghi phần còn chưa hoàn thành cùng hành động tiếp theo.
